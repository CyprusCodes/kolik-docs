# Manage driving licence classes

On [Admin Panel → Organization Structure → Driving Licence Classes](https://app.kolik.co/dashboard/admin-panel?tab=organization-structure&subTab=license-classes), manage the classes used by your organization.

- Click **Add Licence Class**, enter a name, and create a class.
- Use **Edit** in the list to change its name.
- Read the confirmation dialog before using **Delete**.

The system rejects a duplicate name within the same organization. This page is unrelated to leave types; it manages driving licence class options for employees.
