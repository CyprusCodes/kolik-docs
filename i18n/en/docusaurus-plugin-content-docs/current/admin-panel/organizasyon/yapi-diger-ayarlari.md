# Organization structure tabs

[Admin Panel → Organization Structure](https://app.kolik.co/dashboard/admin-panel?tab=organization-structure) contains the subtabs below. **Shift Types** appears only when the Shift Calendar app is enabled for the organization. For a department's leave policy, see [Departments](./departmanlar); for driving licence classes, see [Driving Licence Classes](./ehliyet-siniflari).

| Subtab | Add and edit | Delete / limitation |
| --- | --- | --- |
| [Departments](https://app.kolik.co/dashboard/admin-panel?tab=organization-structure&subTab=departments) | Enter a name with **Add Department**; rename with **Edit**; open people and leave defaults via the name or **View**. | No delete button in this list. |
| [Positions](https://app.kolik.co/dashboard/admin-panel?tab=organization-structure&subTab=positions) | **Add Position** → name → **Add**. Use **Edit** on an existing row, change the name, and **Save**. | No delete button on this screen. |
| [Shift Types](https://app.kolik.co/dashboard/admin-panel?tab=organization-structure&subTab=shift-types) | **Add Shift Type** and enter a name, color, start time, and end time. Edit from the row. | Deleting from a row requires confirmation. |
| [Contract Types](https://app.kolik.co/dashboard/admin-panel?tab=organization-structure&subTab=employee-entitlement-types) | Add a type and name it; use **All / Default / Custom** to filter. | Only organization-specific types can be edited or deleted; system defaults are protected. |
| [Meeting Room Equipment](https://app.kolik.co/dashboard/admin-panel?tab=organization-structure&subTab=equipment) | **Add Equipment** → equipment name → **Add**. | Row deletion requires confirmation; there is no edit button. |
| [Custom Fields](https://app.kolik.co/dashboard/admin-panel?tab=organization-structure&subTab=custom-fields) | Use **Add Custom Field** to set a name and type; edit from the row. | Row deletion requires confirmation. |
| [Driving Licence Classes](https://app.kolik.co/dashboard/admin-panel?tab=organization-structure&subTab=license-classes) | Add or edit a class name. | Deletion requires confirmation; names must be unique. |

## Creating a custom field

Select a **Field name** and **Field type**. Types include text, multiline text, number, date, time, date-time, checkbox, yes/no/not applicable, dropdown, multiselect, checklist, file, and signature. Add list items for option-based types. **Required** and **Employee can edit** control the field's behavior. This list is for general custom fields; personal-information fields are managed separately in the employee bulk-upload flow.
