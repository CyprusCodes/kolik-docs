# Admin Panel

This guide is for people who manage company settings in Kolik. **Company administrators** and **super administrators** can access the panel. Open **Admin Panel** from the sidebar and switch among the tabs at the top. If a tab is absent, check whether the relevant app is enabled for your organization.

![Admin Panel tab groups](/img/en/admin/admin-panel-map.svg)

*Illustrative navigation diagram, not a screenshot.*

| Tab | What you can do |
| --- | --- |
| [Company Information](./sirket-bilgileri) | View/edit company name, industry, website, and country; switch within a group of companies. |
| [Users](./kullanicilar) | Search and filter users; edit roles and status. |
| [Company Bank Details](./banka-hesaplari) | Add/edit bank accounts and contact people. |
| [Public Holidays](./resmi-tatiller) | Add, edit, and delete holidays. |
| [Leave](./izinler/) | Leave types, policies, entitlements, and approval workflows. |
| [Organization Structure](./organizasyon/yapi-diger-ayarlari) | Departments, positions, shift types, contract types, equipment, custom fields, and license classes. |
| [Timesheets](./puantaj) | Work sites, overtime types, and timesheet settings; shown only when the app is enabled. |
| [Birthday Manager](./dogum-gunleri) | Birthday reminders and recipients. |
| [Organization Settings](./organizasyon-ayarlari) | Document expiry alerts, employee access, and email configuration. |
| [Activity Log](./etkinlik-gunlugu) | Filter and export administrative actions. |

:::info Direct links
Application links in these guides point to the live site at `https://app.kolik.co/`. The `?tab=` parameter opens the corresponding top tab; `&subTab=` opens a subtab. Extra parameters such as `admin-panel-organization-users-dt--...` only preserve table sorting or pagination and are not needed to open a tab. Sign in with an authorized account.
:::
