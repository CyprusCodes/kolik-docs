# Manage users and their roles

[Admin Panel → Users](https://app.kolik.co/dashboard/admin-panel?tab=users) lists each user's name, email, role, status, and creation date. Use the search field to find a person. You can also filter and sort table columns and move between pages.

## Change a role or status

1. Click the **edit** icon on the user's row.
2. Select the new organization role under **Role**. Set **Status** to **Active** or **Inactive**.
3. Click **Save**. The email address is displayed in this dialog but cannot be edited here.

The edit button is disabled for super administrator rows. This tab has no buttons to add or delete users; it is for managing existing organization users.
