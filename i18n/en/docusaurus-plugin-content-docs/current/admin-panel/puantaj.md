# Timesheets

[Admin Panel → Timesheets](https://app.kolik.co/dashboard/admin-panel?tab=timesheets) appears only when the Timesheets app is enabled for the organization. It has three subtabs:

## Work sites

Under [Work Sites](https://app.kolik.co/dashboard/admin-panel?tab=timesheets&subTab=work-sites), click **Add Work Site** and enter a site name and optional address. Use **Edit** on an existing row to change them, or **Delete** and confirm to remove the site. A site can be selected when creating a timesheet entry; historical entries retain their site information after deletion.

## Overtime types

Under [Overtime Types](https://app.kolik.co/dashboard/admin-panel?tab=timesheets&subTab=overtime-types), click **Add Overtime Type** and enter a name and **Hourly Rate**. Use **Edit** or **Delete** on a row to update or remove it, with confirmation for deletion. A deleted type remains on historical entries but cannot be selected for new ones.

## Configuration

Under [Settings](https://app.kolik.co/dashboard/admin-panel?tab=timesheets&subTab=config):

- **Allow employees to add their own entries** controls self-entry. **Require approval for employee-added entries** determines whether those entries enter an approval process.
- Select **Working days** and enter a **non-working-day multiplier** for compensation on those days.
- Click **Save Changes** to save the configuration.

This page manages settings. Daily entries are kept on the separate Timesheets working screen.
