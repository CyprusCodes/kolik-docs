# Birthday reminders

Use [Admin Panel → Birthday Manager](https://app.kolik.co/dashboard/admin-panel?tab=birthday-manager) to configure reminders for upcoming birthdays. This page manages **reminders and recipients**; it does not create birthday records.

1. Turn **Send upcoming birthday reminders** on or off. This change is sent immediately; no separate Save button is needed.
2. Set **Reminder Mode** to **Management** or **Selected**. In Management mode, users with management roles receive reminders. In Selected mode, you can turn recipients on or off individually using the person cards below.
3. The cards show each person's name, role, position, and department. Individual recipient selection is unavailable when reminders are off or Management mode is selected.

This tab does not allow you to add or edit an employee's birth date or delete an employee.
