# Manage public holidays

[Admin Panel → Public Holidays](https://app.kolik.co/dashboard/admin-panel?tab=national-holidays) shows each holiday's name, date range, type, days remaining, status, and available actions.

## Add a holiday

1. Click **Add Holiday**.
2. Enter a **Holiday name** and **Start date**. For a multi-day holiday, optionally select an **End date**.
3. Turn on **Recurring holiday** if it repeats every year.
4. Choose **National**, **Religious**, or **Cultural** as the type, and optionally add a description.
5. Click **Add**.

Use the **edit** icon on an existing holiday to change the same fields. To remove it, use the **delete** icon and confirm. Whether a holiday within a leave request is deducted from the balance is controlled separately in that [leave policy's calculation settings](./izinler/politika-hesaplama-ayarlari).
