# Review the activity log

[Admin Panel → Activity Log](https://app.kolik.co/dashboard/admin-panel?tab=activity-log) shows administrative actions in **Date/Time**, **Actor**, **Action**, and **Related Object** columns. You can filter and sort columns, move between pages, and export the table.

Names of undeleted objects such as employee or leave request records may open as links. Deleted records and other objects appear only as text. This page is read-only: you cannot add, edit, or delete records here.
