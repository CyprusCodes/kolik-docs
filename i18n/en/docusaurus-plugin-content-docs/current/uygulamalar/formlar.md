# Forms

Select **Forms** from enabled apps or open the [forms list](https://app.kolik.co/dashboard/forms). There is no separate module sidebar; the form builder and submissions open from form rows.

## Create and edit a form

Company and super administrators can click **New Form** to create a blank form. In the builder, enter a title. Under **Fields**, add fields or groups, reorder them, change settings, and remove unused fields. Under **Settings**, edit the slug, submit-button text, and form options. Use **Preview** to check the respondent view, then click **Save**. Open an existing form from the list to edit it in the same builder.

## Share and review submissions

Use **Share** on a form row to get its link and access information. **View Submissions** in the builder or the list action opens that form's response table. Review responses there. To remove a form, choose **Delete** in the list and confirm. Because deletion can affect response history, check any data you need first.

:::note Permissions
Creating forms and managing the list are available to company and super administrators. If the Forms app is disabled for the organization, the page displays a notice.
:::
