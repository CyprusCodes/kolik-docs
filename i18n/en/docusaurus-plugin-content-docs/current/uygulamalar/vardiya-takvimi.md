# Shift calendar

Select **Shift Calendar** from enabled apps or open the [calendar](https://app.kolik.co/dashboard/shift-calendar). There is no separate internal sidebar. The calendar groups employees by position and displays one week; use the left and right arrows at the top to change weeks.

## Assign or edit a shift

Select the employee's cell for the relevant day. In the dialog, choose a **shift type**, **date**, **start**, and **end** time, then save. Selecting a type fills in default hours, which you can change. Selecting an occupied cell lets you edit its shift or choose **Delete** and confirm. The end time must be after the start.

If the shift type is missing, use **new shift type** in the same dialog to create one with a name, color, and default hours. For general organization definitions, see [Admin Panel → Organization Structure](../admin-panel/organizasyon/yapi-diger-ayarlari).
