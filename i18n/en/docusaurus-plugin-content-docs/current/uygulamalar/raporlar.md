# Reports

Select **Reports** from enabled apps or open the [report builder](https://app.kolik.co/dashboard/reports). This module has no separate internal sidebar; report type, fields, and results are managed on one page.

## Build a report

1. Select the data group to report on. Available groups depend on the report schema returned by the server.
2. Select the columns and fields to display. Use the **Columns** dialog to change visible fields.
3. Add filters and sorting if needed. The page reloads results based on the selected settings.
4. Review the results table and use pagination for additional records.

**Save as template** to reuse a layout. You can later load a template for the same data group or delete an unneeded one after confirmation. Export results as **CSV** or **Excel**. Export uses the selected columns.
