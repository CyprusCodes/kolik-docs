# Apps

Manage Kolik's additional modules on the [Apps](https://app.kolik.co/dashboard/apps) page. This is a catalog: its toggle **enables or disables** an app for the organization. To open an enabled app, use the dashboard's **app switcher**. In some organizations, enabled modules also appear directly under **Apps** in the sidebar.

![Navigation from the app catalog to a module](/img/en/apps/app-navigation.svg)

*Illustrative diagram, not a screenshot.*

| Section | What you can do |
| --- | --- |
| [App Catalog](./uygulama-katalogu) | Enable/disable apps; super administrators can add, edit, and delete catalog entries. |
| [Fleet](./arac-takibi) | Vehicles, sales, vehicle files, service, and settings. |
| [Inventory](./envanter) | Inventory items, assignment history, filters, and trash. |
| [Learning](./ogrenme) | Course catalog, employee learning, content studio, assignments, and analytics. |
| [Performance](./performans) | Review cycles, KPIs, OKRs, surveys, and personal performance. |
| [Timesheets](./zaman-cizelgeleri) | Time entries, payroll settings, advances/deductions, and payroll periods. |
| [Reports](./raporlar) | Choose fields/filters, prepare reports, use templates, and export. |
| [Shift Calendar](./vardiya-takvimi) | Assign, edit, and delete weekly shifts. |
| [Forms](./formlar) | Create forms, edit fields, share, and view responses. |

:::info Visibility
An app or action is visible only when enabled for the organization and allowed for the user role. Adding a catalog entry does not automatically create a new frontend screen; the screen must be developed separately.
:::
