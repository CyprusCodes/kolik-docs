# Inventory

Select **Inventory** from enabled apps or open the [Inventory page](https://app.kolik.co/dashboard/inventory). This module uses filters and record actions on the page rather than a separate module sidebar.

## Add and edit an item

An authorized administrator uses **Add New Item** to enter the name, supplier, location, category, returnability, purchase date, warranty end, last service date, unit cost/currency, status, and any custom attributes. Open **Edit** from an existing item's action menu to change and save its details.

## Filters and assignments

Use **All**, **Warranty Expired**, and **Service Overdue** views. An item's details/assignment history shows its current assignee, return status, and previous movements. If authorized, assign it to an employee, record a return, and update related notes or status.

## Delete and restore

With management permission, choose **Delete** and confirm. Deleted items appear in **Trash**; use **Restore** there to return an accidentally removed item to the list. Trash is not visible to every role.
