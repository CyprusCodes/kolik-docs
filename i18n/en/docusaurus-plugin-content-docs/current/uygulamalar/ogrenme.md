# Learning

Select **Learning** from enabled apps or open the [Learning page](https://app.kolik.co/dashboard/learning). The module has its own sidebar. The standard view includes **Course Catalog**, [Onboarding Guide](https://app.kolik.co/dashboard/learning/onboarding), and [Help / FAQ](https://app.kolik.co/dashboard/learning/support). Authorized managers also see [Content Studio](https://app.kolik.co/dashboard/learning/manage).

## Employee view

The Learning home page shows assigned content, your progress, and available courses. Open a course and complete its pages. The Onboarding Guide contains starting-work material; Help / FAQ contains questions and answers. Visible content depends on assignments and publication status.

## Content Studio menu

Company administrators, super administrators, HR managers, and department managers can access the studio. Its menu contains:

| Menu | Task |
| --- | --- |
| [Curriculum Builder](https://app.kolik.co/dashboard/learning/manage) | Create and edit programs/learning paths, modules/units, sections, and lesson pages; manage drafts, publication, and deletion. |
| [Onboarding Guides](https://app.kolik.co/dashboard/learning/manage/onboarding) | Manage title, category, description, content, order, and draft status. |
| [FAQ Management](https://app.kolik.co/dashboard/learning/manage/faqs) | Add, edit, reorder, and remove questions and answers. |
| [Assignments](https://app.kolik.co/dashboard/learning/manage/assignments) | Assign a program or unit to an employee, department, or everyone; set deadlines and remove assignments. |
| [Progress Analytics](https://app.kolik.co/dashboard/learning/manage/reports) | Review completion and progress. |
| [Feedback](https://app.kolik.co/dashboard/learning/manage/feedback) | Review content ratings. |

For new material, build the curriculum hierarchy first, then fill in pages and check publication status. When needed, select an audience under **Assignments** so employees can see it. If Content Studio is absent, check your role and whether the app is enabled.
