# My Account and profile settings

Click the **profile icon** at the top right of Kolik and choose **Settings**. This opens [My Account](https://app.kolik.co/dashboard/account). It is not a fixed item in the main sidebar.

![Tabs and actions on the My Account page](/img/en/dashboard/account-settings-map.svg)

*Illustrative navigation diagram, not a screenshot.*

| Tab | What you can do |
| --- | --- |
| [General](./genel) | Profile photo, name, date of birth, personal details, and emergency contacts. |
| [Bank Details](./banka-bilgileri) | Add/edit bank accounts for salary payments and view their status. |
| [Notifications](./bildirimler) | Choose preferences for leave, support, meetings, documents, and other notifications. |
| [Change Password](./sifre-degistir) | Set a new password using your current one. |

These tabs belong to your user account. Use the [Admin Panel](../../admin-panel/) for company-wide rules. Bank and personal-information cards are linked to your employee record in the selected organization. If there is no such record, some cards may be missing or display an information notice.

:::info Available features
The codebase contains separate components for billing, team management, and login history, but they are not active tabs on this page. This guide covers only the four tabs you can currently open.
:::
