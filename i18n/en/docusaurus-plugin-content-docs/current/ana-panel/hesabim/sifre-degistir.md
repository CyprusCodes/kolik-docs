# Change password

In [My Account → Change Password](https://app.kolik.co/dashboard/account?tab=security), enter **Current Password**, **New Password**, and **Confirm Password**, then click **Save**. A successful change shows a confirmation and refreshes your session access information.

The new password must be **8–20 characters** long and contain at least one **uppercase letter**, one **digit**, and one of `@ $ ! % * # ? &`. Confirmation must match the new password. The form shows field errors for unmet rules. If the current password is wrong, read the server's field error. If changing it still fails, refresh your session and try again.

:::note Not on this page
Multi-factor authentication and login history are not active on this tab; there are no setup steps for features you cannot see.
:::
