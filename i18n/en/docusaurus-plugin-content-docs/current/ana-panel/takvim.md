# Calendar

Open [Calendar](https://app.kolik.co/dashboard/calendar) from the sidebar. **Public holidays** and **approved leave** appear with colored markers. If Google Calendar or Microsoft 365 is connected, its events appear in their own colors. Use the top toolbar to jump to today, move between periods, or change calendar view; use **Refresh** to reload the data.

## Connect a personal calendar and add events

Choose **Google Calendar** or **Microsoft 365** from **Connect** and complete the authorization flow. Once connected, you can use **Add Event** or select a time range on the calendar. Enter a title, date/time, description, and location, then save. Select an existing personal event to edit or delete it. In supported views, dragging or resizing also updates its date/time.

Without a connected calendar, personal event creation is unavailable, but you can still view public holidays and approved leave. If you see **Google connection expired**, click **Reconnect**. If authorization or saving fails, recheck the connection and the form's required fields; the end time must be after the start.
