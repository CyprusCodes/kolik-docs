# Dashboard and sidebar

After signing in, Kolik opens the [Dashboard](https://app.kolik.co/dashboard). Sidebar links depend on your role and the apps enabled for your organization. If you cannot see a link described here, check that you selected the correct organization and have the required permission.

![Kolik dashboard sidebar diagram](/img/en/dashboard/main-sidebar.svg)

*Illustrative diagram, not a screenshot.*

| Sidebar item | Guide |
| --- | --- |
| [Dashboard](./ana-sayfa) | Summary cards and quick links. |
| [Employees](./calisanlar) | Employee list, invitations, profile tabs, and record management. |
| [Leave](./izinler) | Create requests, track status, and approve leave. |
| [Payroll](./bordro) | Payroll groups, periods, processing, and documents. |
| [Meeting Rooms](./toplanti-odalari) | Rooms, bookings, and calendar. |
| [Support Tickets](./destek-talepleri) | Create tickets, communicate, track status, and manage categories. |
| [Calendar](./takvim) | Holiday/leave view and connected personal calendar. |
| [AI Assistant](./ai-asistan) | Beta chat screen. |
| [My Account](./hesabim/) | Personal details, banking, notifications, and password under the profile menu's Settings. |
| [My Performance](./performansim) | Personal reviews and results when the Performance app is enabled. |
| [Apps](../uygulamalar/) | Additional modules and catalog; available to company administrators. |

**Payroll** is available to appropriate roles, such as company administrators and accounting users; **Apps** is available to company administrators. **My Performance** appears when the Performance module is enabled. These main-menu pages are separate from [additional app modules](../uygulamalar/). For example, main-menu **Payroll** and **Timesheets → Payroll Periods** are different screens.

[Admin Panel](../admin-panel/) is a separate management area rather than a fixed item in the main sidebar. **My Account** opens from **Settings** in the top-right profile menu, not the left sidebar.

:::info Application links
Links point to the live site at `https://app.kolik.co/`. Sign in with an organization account to access the pages; menu items vary by role.
:::
