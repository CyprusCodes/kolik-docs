# Bildirim tercihleri

**[Hesabım → Bildirimler](https://kolik.co/dashboard/account?tab=notifications)** sekmesinde almak istediğiniz bildirimleri anahtarlarla açıp kapatın. Değişikliklerin geçerli olması için alttaki **Kaydet** düğmesine basın; anahtarı çevirmek tek başına kaydetmez.

| Bildirim | Kimler görebilir? |
| --- | --- |
| İzin talebime yanıt, destek talebime yanıt, toplantı odası talebime yanıt | Genel kullanıcı rolleri. |
| Kendi belgemin süresi doluyor | Genel kullanıcı rolleri. |
| Yeni izin talebi, çalışan belgesi süresi, günlük izinli listesi | Şirket yöneticisi ve İK yöneticisi. |
| Yeni destek talebi | Şirket yöneticisi ve BT yöneticisi. |
| Yeni toplantı odası talebi | Şirket yöneticisi. |
| Onay bekleyen zaman çizelgesi kaydı | Şirket yöneticisi. |

Görünen anahtarlar rolünüze bağlıdır; bazı satırlar çalışan hesabında hiç görünmez. Ayarlar yüklenemez veya kaydedilemezse sayfa bildirim gösterir. Kaydetme başarılı olunca onay mesajı çıkar. **Belge süresi** seçeneklerinden bazıları FE'de hâlen İngilizce etiketlerle görüntülenebilir.
