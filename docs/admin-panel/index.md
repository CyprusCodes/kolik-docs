# Yönetici Paneli

Bu kılavuz, Kolik'te şirket ayarlarını yöneten kişiler içindir. Panele **şirket yöneticisi** veya **süper yönetici** erişebilir. Sol menüden **Yönetici Paneli**'ni açın; üstteki yatay sekmeler arasında geçin. Bir sekme görünmüyorsa uygulamanın kuruluşunuzda etkin olup olmadığını kontrol edin.

![Yönetici Paneli sekmelerinin konu grupları](/img/admin/admin-panel-map.svg)

*Temsili gezinme görseli; gerçek ekran görüntüsü değildir.*

| Sekme | Neler yapılır? |
| --- | --- |
| [Şirket Bilgileri](./sirket-bilgileri) | Şirket adını, faaliyet alanını, web sitesini ve ülkeyi görüntüleme/düzenleme; şirketler grubunda geçiş. |
| [Kullanıcılar](./kullanicilar) | Kullanıcıları arama, filtreleme; rol ve durumu düzenleme. |
| [Şirket Banka Bilgileri](./banka-hesaplari) | Banka hesabı ve iletişim kişileri ekleme/düzenleme. |
| [Resmî Tatiller](./resmi-tatiller) | Tatil ekleme, düzenleme ve silme. |
| [İzinler](./izinler/) | İzin türleri, politikalar, haklar ve onay akışı. |
| [Organizasyon Yapısı](./organizasyon/yapi-diger-ayarlari) | Departmanlar, pozisyonlar, vardiya türleri, sözleşme türleri, ekipman, özel alanlar ve ehliyet sınıfları. |
| [Zaman Çizelgeleri](./puantaj) | Çalışma sahaları, ek mesai türleri ve zaman çizelgesi ayarları. Yalnızca uygulama etkinse görünür. |
| [Doğum Günü Yöneticisi](./dogum-gunleri) | Doğum günü hatırlatmaları ve alıcıları. |
| [Organizasyon Ayarları](./organizasyon-ayarlari) | Belge süresi bildirimleri, çalışan erişimi ve e-posta yapılandırması. |
| [Etkinlik Günlüğü](./etkinlik-gunlugu) | Yönetim işlemlerini filtreleme ve dışa aktarma. |

:::info Doğrudan bağlantılar
Rehberdeki uygulama bağlantıları canlı `https://app.kolik.co/` adresine gider. Bağlantıdaki `?tab=` ilgili üst sekmeyi, `&subTab=` alt sekmeyi açar. Örnekteki `admin-panel-organization-users-dt--...` gibi ek parametreler yalnızca tablo sıralama/sayfalama durumudur; ilgili sekmeye gitmek için gerekmez. Erişim için uygun yetkili hesapla oturum açın.
:::
